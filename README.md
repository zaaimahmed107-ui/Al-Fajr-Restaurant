# 🍔 Al Fajr Restaurant

A full-stack restaurant management website built with modern web technologies.  
The system allows customers to browse food items, add items to cart, place orders, and track orders. Admins can manage food items and orders through a dashboard.

## 🚀 Live Website

https://zaaimahmed107-ui.github.io/Al-Fajr-Restaurant/

## ✨ Features

### Customer Side
- 🍽️ Dynamic food menu
- 🛒 Add to cart system
- 📦 Checkout and order placement
- 🔎 Track order status

### Admin Side
- 🔐 Admin login
- 📊 Dashboard
- 🍔 Add/Edit/Delete food items
- 📦 Manage customer orders
- 🔄 Update order status

## 🛠️ Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript
- Bootstrap 5

### Backend
- Node.js
- Express.js

### Database
- MongoDB Atlas

### Deployment
- GitHub Pages (Frontend)
- Railway (Backend)
